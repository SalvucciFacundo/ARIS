# Design: ARIS ComfyUI Workflow JSON Export & Metadata Interoperability

## 1. Architecture Overview

This design implements pure-Go PNG chunk parsing and manipulation to embed metadata (like generation parameters and ComfyUI workflow graphs) into PNG files generated by ARIS. The architecture consists of a core PNG utility package, adapter-specific metadata injection, and CLI commands for inspection and extraction.

## 2. Component Details

### 2.1 Pure-Go PNG Chunk Manipulation Pipeline (`pkg/imgutil/png_chunks.go`)

PNG files consist of an 8-byte signature followed by a series of chunks. Each chunk has:
- **Length**: 4 bytes (uint32)
- **Type**: 4 bytes (e.g., `IHDR`, `IDAT`, `tEXt`, `IEND`)
- **Data**: `Length` bytes
- **CRC-32**: 4 bytes (calculated over Type + Data using IEEE polynomial)

To avoid holding full uncompressed image rasters in memory, the pipeline uses a streaming read-copy-write approach:
1. **`InjectMetadata(r io.Reader, w io.Writer, meta map[string]string) error`**:
   - Verify the 8-byte PNG signature (`\x89PNG\r\n\x1a\n`). Write it to `w`.
   - Iterate through chunks in `r`.
   - Copy each chunk to `w` as-is, **except** when `Type == "IEND"`.
   - Before writing `IEND`, construct and write a `tEXt` chunk for each key-value pair in `meta`.
   - The `tEXt` chunk data format is: `Keyword (1-79 bytes) + \x00 + Text string`.
   - Calculate the CRC-32 (using `hash/crc32.IEEETable`) for the new chunk.
   - Finally, write the `IEND` chunk.
2. **`ExtractMetadata(r io.Reader) (map[string]string, error)`**:
   - Verify the PNG signature.
   - Iterate through chunks, skipping data (using `io.CopyN(io.Discard, ...)`) for non-metadata chunks.
   - Parse `tEXt` chunks: split the chunk data by the first null byte (`\x00`) to extract the key and value.
   - Validate the CRC-32 checksums of the chunks being parsed to ensure integrity.

### 2.2 ComfyUI Backend Workflow Injection (`internal/adapters/image/comfyui.go`)

The ComfyUI adapter requires the full node graph to enable drag-and-drop interoperability.
- During execution, the adapter holds the `prompt` (the executable node map) and `workflow` (the UI layout node map).
- Upon receiving the generated image bytes from the ComfyUI API, it wraps the byte slice in a `bytes.Reader`.
- It marshals `prompt` and `workflow` to minified JSON strings.
- Calls `imgutil.InjectMetadata` with map keys `"prompt"` and `"workflow"`, writing the output to a new buffer or directly to the target file.
- The augmented image file is then saved to disk.

### 2.3 Multi-Backend Metadata Embedding

To unify generation tracking across ComfyUI, Fal.ai, Pollinations, and OpenAI:
- A standardized `parameters` structure is defined (Prompt, Model, Seed, Aspect Ratio, Steps, CFG).
- Non-ComfyUI adapters (or the central image repository) marshal this structure to JSON.
- `imgutil.InjectMetadata` is called to embed this JSON under the `parameters` `tEXt` keyword.
- This creates universally reproducible PNGs matching A1111/Civitai tracking standards.

### 2.4 CLI Subcommand `aris workflow`

A new subcommand tree added to the CLI:

- **`aris workflow inspect <image.png> [--json]`**:
  - Opens the file, calls `ExtractMetadata`.
  - If `--json`, marshals the entire extracted map to JSON and prints to stdout.
  - Otherwise, parses the `prompt` or `parameters` JSON, calculates node counts, and prints a formatted terminal summary table.
- **`aris workflow export <image.png> [-o <path>] [-f|--force]`**:
  - Calls `ExtractMetadata`. Checks if the `"workflow"` key exists.
  - Determines destination path (defaults to `<image-basename>.workflow.json`).
  - Checks if the file exists. If so, fails with instructions to use `-f/--force` unless the flag is provided.
  - If `-o -` is provided, dumps the raw `workflow` string to stdout.
  - Otherwise, writes the string to the destination file.

## 3. Flow & Sequence Diagrams

### 3.1 Metadata Injection Flow

```ascii
+-------------+      +-------------------+      +-------------------------+
| ComfyUI API |      | internal/adapters |      | pkg/imgutil/png_chunks  |
+-------------+      +-------------------+      +-------------------------+
       |                       |                             |
       |--- Image Bytes ------>|                             |
       |                       |                             |
       |                       |-- JSON marshal `prompt`     |
       |                       |-- JSON marshal `workflow`   |
       |                       |                             |
       |                       |--- InjectMetadata(r,w,m) -->|
       |                       |                             |-- Read Signature
       |                       |                             |-- Read/Copy Chunks
       |                       |                             |-- Intercept IEND
       |                       |                             |-- Write tEXt chunks
       |                       |                             |-- Write IEND
       |                       |<--- (Augmented Bytes) ------|
       |                       |                             |
       |                       |-- Save PNG to disk          |
```

### 3.2 CLI Export Flow

```ascii
[ User ] -- aris workflow export render.png --> [ CLI router ]
                                                      |
                                               [ ExtractMetadata ]
                                                      |
                                       (Reads chunks, finds "workflow")
                                                      |
                         <-- returns map{"workflow": "{...}", "prompt": "{...}"}
                                                      |
                             [ Check os.Stat(dest) for overwrite protection ]
                                                      |
                                     [ Write value to destination file ]
```

## 4. Testing Strategy (Strict TDD)

The implementation strictly follows RED -> GREEN -> TRIANGULATE -> REFACTOR.

### 4.1 Chunk Manipulation (`pkg/imgutil/png_chunks_test.go`)
- **Unit: `TestInjectAndExtractMetadata_RoundTrip`**: Generate a minimal valid 1x1 synthetic PNG in memory. Inject `{"test_key": "test_val"}`. Extract it and verify the value.
- **Unit: `TestExtractMetadata_InvalidSignature`**: Provide a JPEG byte sequence, verify it returns `ErrInvalidPNGSignature`.
- **Unit: `TestExtractMetadata_CorruptedCRC`**: Generate a valid PNG, manually alter one byte in a chunk's data segment, verify extraction fails with `ErrInvalidChunkCRC`.
- **Unit: `TestExtractMetadata_NoMetadata`**: Ensure passing a standard PNG without `tEXt` chunks gracefully returns an empty map without error.

### 4.2 Adapter Integration (`internal/adapters/image/comfyui_test.go`)
- **Unit: `TestComfyUIAdapter_EmbedsWorkflow`**: Mock the ComfyUI HTTP client to return a static PNG. Verify that the file saved by the adapter successfully passes `ExtractMetadata` and contains the expected JSON strings.

### 4.3 CLI Integration (`cmd/workflow_test.go`)
- **Unit: `TestCLIWorkflowExport_Success`**: Mock `imgutil.ExtractMetadata`, execute `export`, and verify the generated JSON file contents.
- **Unit: `TestCLIWorkflowExport_FileExists`**: Ensure `export` without `--force` returns a non-zero exit code when the target file exists, and that passing `--force` overwrites it.
- **Unit: `TestCLIWorkflowInspect_JSON`**: Verify that the `--json` flag prints valid raw JSON containing all keys.
